Privacy policy

Last updated: 10 October 2026.

Hermes planner is used by one person, its owner. It requests access to the owner's Google Calendar (read-only, plus a calendar the app creates itself) and Google Tasks.

  • What it uses: calendar events and tasks, only to answer the owner's own questions and to create or update the owner's own events and tasks.
  • Where it is kept: the sign-in token is stored on the owner's private server. Calendar and task data is not stored beyond what is needed to answer a request.
  • Sharing: data is never sold, shared with third parties, or used for advertising.
  • Google user data use complies with the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: at any time at myaccount.google.com/permissions.
